# Fictional local-only project: AI Workspace owns ideas and decisions

**All people, conversations, decisions and outcomes in this example are invented.** It is a documentation exercise, not a real project or approved implementation.

Unlike the [Note CLI example](../sample-project/README.md), **Quiet Notes** has no external idea or decision system.

- [INFORMATION.md](INFORMATION.md) designates AI Workspace as the durable home for **ideas, decisions and exploratory knowledge**; it does **not** authorize implementation or create a task tracker.
- [IDEAS.md](IDEAS.md) contains a **deliberately materialized** idea: plain-text export. It is marked proposed, not approved for implementation. **There is no second pending copy** of that same idea.
- [PENDING.md](PENDING.md) holds a *different* conversation: shared-device synchronization, still paused and not yet registered as a durable idea.
- [DECISIONS.md](DECISIONS.md) shows a fictional locally recorded design choice; do not interpret its illustrative approval as a real user's authorization.
- [HANDOFF.md](HANDOFF.md) directs a read-only learner to distinguish these states.

## Try it

Ask an agent with **read-only** access:

> Read only this fictional example. Where are ideas and decisions recorded? Which topic is already materialized? Which is pending? What may be done next without further authorization?

Expected: plain-text export is an **existing local idea** (not a task), shared-device sync is **pending**, and no implementation or task transition is authorized. If later recorded in local `IDEAS.md`, the shared-sync pending note can be retired **only after its content is verified in that file**.

No GitHub, Backlog.md, or external account is required to use AI Workspace as a local knowledge store.
