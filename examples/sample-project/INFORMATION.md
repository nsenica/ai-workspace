# Note CLI — fictional information ownership

**Illustrative only.** No real external tracker, source repository or approval authority is accessible in this example.

| Category | Canonical destination | Status / authorization |
| --- | --- | --- |
| Ideas | Fictional **external** tracker (unavailable) | Creating an idea requires separate operator authorization; no confirmed idea record exists |
| Decisions | [Local DECISIONS.md](DECISIONS.md) | Proposed notes may be recorded; approval belongs to the operator |
| Tasks / acceptance | Fictional **external** tracker (unavailable) | No task state can be checked or changed |
| Research | Local `knowledge/` if needed | Not a substitute for authoritative source |
| Evidence | Local `evidence/` or restricted durable store | Claims must distinguish reporting from verification |
| Live state | Not applicable | No deployment |

**Coordination:** [HANDOFF.md](HANDOFF.md) is the current state, and [PENDING.md](PENDING.md) holds a meaningful unfinished discussion. Neither grants tracker access or task approval.

The discussion about offline note search remains pending **because it was paused before any authorized tracker record was made**. If later materialized in the external tracker, the agent must confirm the destination entry by read-back before removing the pending copy.
